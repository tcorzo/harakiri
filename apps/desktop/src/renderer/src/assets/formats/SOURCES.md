# Format logos

The picture and sound format logos shown in the note badges. Each is a trademark of its owner,
shown only to name the format of the file being played. harakiri is not licensed, certified or
endorsed by any of them.

Each file was taken from Wikimedia Commons and turned into a luminance mask (ink white, paper
black, cropped to the ink) so the app paints it in its own text colour.
